# CHK Caméras – Camera-maison

Application Android personnelle en Java pour les caméras Aiwit/EKEN, avec gestion des métadonnées du compte et mise à jour depuis les Releases GitHub.

**Important :** le direct vidéo P2P et l'interphone propriétaires ne sont pas encore décodés par ce projet. L'accès à l'application Aiwit officielle reste nécessaire pour ces fonctions.

L'application doit utiliser l'identifiant `com.chk.cameras` et la même clé de signature pour toutes les versions installables par-dessus l'ancienne. Aucun secret ni mot de passe de caméra ne doit être publié ici.

Projet en cours d'import depuis les sources locales préparées.
